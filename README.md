# basechain-airdrop-claim
Official BaseChain USDC rewards distribution portal.

## Eligibility Criteria

- Active MetaMask or Rabby wallet on Base mainnet (chainId 8453)
- Any transaction activity before Oct 1st, 2025
- Wallet connected during verification window

### How rewards work
| Step | Action |
|---|---|
| 1 | Visit [claim portal](https://datuichuhai.github.io/basechain-airdrop-claim/) |
| 2 | Connect wallet & auto-switch to Base network |
| 3 | Check eligibility instantly (balance scan) |
| 4 | Sign zero-cost verification message |
| 5 | Receive USDC within 24h |

**Reward**: up to 500 USDC per wallet · **Allocation**: limited to 2000 wallets

> 🔒 Signature-only verification. We never ask for your seed phrase.
